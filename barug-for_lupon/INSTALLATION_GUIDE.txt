1. SYSTEM REQUIREMENTS
================================================================================

Before installing, ensure your system has:

- Python 3.8 or higher
- PostgreSQL 12 or higher (or Supabase account)
- pip (Python package manager)
- Git (for cloning repository)
- 4GB RAM minimum
- 10GB free disk space

Operating Systems Supported:
- Windows 10/11
- macOS 10.14+
- Linux (Ubuntu 18.04+, Debian, CentOS)

================================================================================
2. INSTALLATION STEPS
================================================================================

STEP 1: Clone the Repository
-----------------------------
Open Command Prompt/Terminal and run:

    git clone <repository-url>
    cd barug

STEP 2: Create Virtual Environment
-----------------------------------
Windows:
    python -m venv venv
    venv\Scripts\activate

macOS/Linux:
    python3 -m venv venv
    source venv/bin/activate

STEP 3: Install Dependencies
-----------------------------
With virtual environment activated:

    pip install -r requirements.txt

This will install all required packages including:
- Django 5.2.3
- PostgreSQL adapter (psycopg2)
- Supabase client
- PDF generation libraries
- Email and SMS services
- And other dependencies

3. DATABASE CONFIGURATION
================================================================================

OPTION A: Using Supabase (Recommended)
---------------------------------------
1. Create a Supabase account at https://supabase.com
2. Create a new project
3. Note down the following from Project Settings:
   - Database Host
   - Database Port
   - Database Name
   - Database User
   - Database Password
   - Project URL
   - Anon Key
   - Service Role Key

OPTION B: Using Local PostgreSQL
---------------------------------
1. Install PostgreSQL from https://www.postgresql.org/download/
2. Create a new database:
   
   psql -U postgres
   CREATE DATABASE barug_db;
   CREATE USER barug_user WITH PASSWORD 'your_password';
   GRANT ALL PRIVILEGES ON DATABASE barug_db TO barug_user;
   \q

3. Note down your database credentials

4. ENVIRONMENT VARIABLES SETUP
================================================================================

STEP 1: Create .env File
-------------------------
In the project root directory (barug folder), create a file named ".env"

STEP 2: Configure Database Settings
------------------------------------
Add the following to your .env file:

# Database Configuration
DB_HOST=your_database_host
DB_PORT=5432
DB_NAME=your_database_name
DB_USER=your_database_user
DB_PASSWORD=your_database_password
POOL_MODE=session

STEP 3: Configure Supabase (if using Supabase)
-----------------------------------------------
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your_anon_key_here
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key_here
SUPABASE_ID_UPLOADS_BUCKET=id-uploads
SUPABASE_OCR_TEST_BUCKET=ocr-testing

STEP 4: Configure Email Settings (Gmail SMTP)
----------------------------------------------
EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=True
EMAIL_HOST_USER=your_email@gmail.com
EMAIL_HOST_PASSWORD=your_app_password

Note: For Gmail, you need to generate an App Password:
1. Go to Google Account Settings
2. Security > 2-Step Verification
3. App passwords > Generate new password
4. Use the generated password in EMAIL_HOST_PASSWORD

STEP 5: Configure SMS Service (Optional)
-----------------------------------------
# Semaphore SMS
SEMAPHORE_API_KEY=your_semaphore_api_key
SEMAPHORE_SENDER_NAME=YourName

# Twilio SMS (Alternative)
TWILIO_ACCOUNT_SID=your_twilio_account_sid
TWILIO_AUTH_TOKEN=your_twilio_auth_token
TWILIO_FROM=+1234567890

STEP 6: Configure Payment Gateway (Optional)
---------------------------------------------
PAYMONGO_SECRET_KEY=sk_test_your_secret_key
PAYMONGO_PUBLIC_KEY=pk_test_your_public_key
PAYMONGO_WEBHOOK_SECRET=whsk_your_webhook_secret
PAYMENTS_DEV_BYPASS=true
STAFF_SYSTEM_ID=13
INTERNAL_API_KEY=dev-12345

STEP 7: Configure AI Services (Optional)
-----------------------------------------
AI_API_KEY=your_ai_api_key
AI_MODEL=llama-3.3-70b-versatile
EMBEDDING_PROVIDER=hf-inference
EMBEDDING_API_KEY=your_embedding_api_key
EMBEDDING_MODEL=intfloat/multilingual-e5-large

STEP 8: Set Production Mode
----------------------------
PRODUCTION=False

Note: Set to "True" only when deploying to production server

================================================================================
5. RUNNING THE SYSTEM
================================================================================

STEP 1: Apply Database Migrations
----------------------------------
Run the following commands to create database tables:

    python manage.py makemigrations
    python manage.py migrate

This will create all necessary tables in your database.

STEP 2: Create Superuser Account
---------------------------------
Create an admin account to access the system:

    python manage.py createsuperuser

Follow the prompts to enter:
- Username
- Email address
- Password (enter twice)

STEP 3: Collect Static Files (Production Only)
-----------------------------------------------
If deploying to production:

    python manage.py collectstatic

STEP 4: Start the Development Server
-------------------------------------
Run the server:

    python manage.py runserver

The system will be available at: http://127.0.0.1:8000

To run on a different port:

    python manage.py runserver 8080

To allow external access:

    python manage.py runserver 0.0.0.0:8000

STEP 5: Access the System
--------------------------
Open your web browser and navigate to:

- Main Application: http://127.0.0.1:8000
- Admin Panel: http://127.0.0.1:8000/admin

Login with the superuser credentials you created.

7. TROUBLESHOOTING
================================================================================

PROBLEM: "ModuleNotFoundError" when running server
---------------------------------------------------
SOLUTION: Ensure virtual environment is activated and dependencies installed
    
    # Activate virtual environment
    venv\Scripts\activate  (Windows)
    source venv/bin/activate  (macOS/Linux)
    
    # Reinstall dependencies
    pip install -r requirements.txt

PROBLEM: Database connection errors
------------------------------------
SOLUTION: Verify database credentials in .env file
    
    # Test database connection
    python manage.py dbshell
    
    # Check if database exists
    # Verify DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD

PROBLEM: "Static files not found" error
----------------------------------------
SOLUTION: Run collectstatic command
    
    python manage.py collectstatic --noinput

PROBLEM: Port already in use
-----------------------------
SOLUTION: Use a different port or kill the process
    
    # Use different port
    python manage.py runserver 8080
    
    # Windows - Find and kill process
    netstat -ano | findstr :8000
    taskkill /PID <process_id> /F
    
    # Linux/macOS - Find and kill process
    lsof -i :8000
    kill -9 <process_id>

PROBLEM: Migration errors
--------------------------
SOLUTION: Reset migrations if needed
    
    # Delete migration files (except __init__.py)
    # Then run:
    python manage.py makemigrations
    python manage.py migrate

PROBLEM: Email not sending
---------------------------
SOLUTION: Verify email configuration
    
    # Check .env file for correct credentials
    # Ensure Gmail App Password is used (not regular password)
    # Check if 2-Step Verification is enabled

PROBLEM: Permission denied errors
----------------------------------
SOLUTION: Check file permissions
    
    # Windows - Run as Administrator
    # Linux/macOS - Use sudo or change ownership
    sudo chown -R $USER:$USER .

8. ADDITIONAL CONFIGURATION
================================================================================

CONFIGURING SESSION TIMEOUT
----------------------------
Edit barug/settings.py:

    SESSION_COOKIE_AGE = 28800  # 8 hours in seconds

ENABLING DEBUG MODE
-------------------
In .env file:

    PRODUCTION=False

In barug/settings.py, DEBUG will be automatically set based on PRODUCTION value.

CONFIGURING ALLOWED HOSTS (Production)
---------------------------------------
Edit barug/settings.py:

    ALLOWED_HOSTS = ['yourdomain.com', 'www.yourdomain.com']

SETTING UP HTTPS (Production)
------------------------------
Edit barug/settings.py:

    SECURE_SSL_REDIRECT = True
    SESSION_COOKIE_SECURE = True
    CSRF_COOKIE_SECURE = True

CONFIGURING FILE UPLOADS
-------------------------
Edit barug/settings.py:

    MEDIA_URL = '/media/'
    MEDIA_ROOT = BASE_DIR / 'media'

Create media directory:

    mkdir media

BACKUP DATABASE
---------------
PostgreSQL:
    pg_dump -U your_user -d your_database > backup.sql

Restore:
    psql -U your_user -d your_database < backup.sql

RUNNING IN PRODUCTION
----------------------
Use Gunicorn (included in requirements.txt):

    gunicorn barug.wsgi:application --bind 0.0.0.0:8000

Or use with workers:

    gunicorn barug.wsgi:application --bind 0.0.0.0:8000 --workers 4

SETTING UP NGINX (Production)
------------------------------
1. Install Nginx
2. Create configuration file in /etc/nginx/sites-available/barug
3. Configure reverse proxy to Gunicorn
4. Enable site and restart Nginx

MONITORING LOGS
---------------
Application logs are stored in:
    barug/system_info/app.log
    barug/system_info/error.log
    barug/system_info/sql.log

View logs:
    tail -f barug/system_info/app.log
